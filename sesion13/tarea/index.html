4. Conclusión

Después de realizar esta comparación, considero que Bootstrap es una herramienta muy útil porque permite crear páginas web de manera más rápida y organizada.

Para mi proyecto final utilizaría Bootstrap como base y CSS propio para personalizar los colores, botones y estilos de mi tienda virtual CHELIA.

También aprendí que conocer CSS es importante para comprender cómo funcionan los diseños y realizar modificaciones cuando sea necesario.
